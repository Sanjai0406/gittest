How to use

  1. Pick a map (top). The date chips and match list narrow what you see.
  2. Click a match to watch it; click several to overlay them. With nothing selected you see every match for the chosen days combined.
  3. Press play (or Space) to replay. All matches start at 0:00, so overlays line up by match time.
  4. Heatmap: switch between traffic, kill, death, loot and storm density. Tick “Build up with timeline” to watch hotspots form.
  5. Legend entries are clickable to hide/show an event type. Hover a marker for details and world coordinates.
  6. Scroll to zoom, drag to pan. “Copy link” saves this exact view.
